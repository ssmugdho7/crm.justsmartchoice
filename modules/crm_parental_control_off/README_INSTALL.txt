CRM Parental Control v1.0.3

MANDATORY INSTALL METHOD
1. Delete /modules/crm_parental_control/ completely.
2. Upload the new crm_parental_control folder from this ZIP.
3. Go to Setup > Modules.
4. If Upgrade Database appears, click it once.
5. Open CRM Parental Control.
6. Click Repair Database.
7. Click Health Check / refresh page.

IMPORTANT
- The folder name must remain crm_parental_control because Perfex module slugs use lowercase folder names.
- The front-end name is CRM Parental Control. No visible underscores should appear.
- This release uses correct Perfex language file paths.
- Deprecated settings tabs are not used.
- Full CRM file backup was replaced with a safe shared-hosting package to avoid Bluehost 503 errors.
