# Payroll Hub — Smart Choice Contractors USA

This release scopes all CSS and JavaScript to Payroll Hub routes, preserves existing payroll records, adds 10 payslip templates, integrates settings under Setup → Settings → Payroll Hub, and exposes project job-cost and integrated 1099/commission reporting.

The module reads CRM staff, department, project, invoice, payment, commission, and subcontractor data where available. It does not alter those external tables.
