# Master CRM Fix

Creates complete segmented CRM backups under:

`public_html/CRM MASTER BACKUP/<date-time-job-id>/`

Output:
- CRM Pack 1.zip, CRM Pack 2.zip, and additional packs as needed
- CRM Database.zip
- BACKUP MANIFEST.json
- EXISTING ARCHIVES REPORT.txt
- EXCLUDED FILES.txt
- RESTORE INSTRUCTIONS.txt

Install through Setup → Modules. Full restoration must be completed through cPanel File Manager or SSH.
