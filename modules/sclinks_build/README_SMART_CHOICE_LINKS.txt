Smart Choice Links v1.1.1
Author: Smart Choice Contractors USA / Harold Cabrera
Quality: ★★★★★

This module combines Favorite Links and Smart Choice Links into one shortcut system.
Keep this folder only: smart_choice_links
Remove/deactivate the old favorite_links folder after confirming this module works.

Main features:
- One star on the left side of CRM search.
- One star on the right side of CRM search.
- No visible Links text in the top bar.
- Compact popup windows.
- Adjustable popup width, row height, icon size, font size, padding, radius, and animation speed.
- Direct Settings page, Help page, and Health Check page to prevent 404 errors.
- Main menu and setup menu search helpers.
- Command palette with Ctrl+K.
- Drag-and-drop link ordering.
- Link placement: Left Star, Right Star, or Both Stars.
- English and Spanish language files only.
- PHP 8.5 compatible.
