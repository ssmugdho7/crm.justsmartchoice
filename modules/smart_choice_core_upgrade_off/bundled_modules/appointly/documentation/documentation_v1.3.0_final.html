Installation & Upgrade Guide

Important: Version 1.3.0 Upgrade Notice

This is a major version upgrade that includes database schema changes and architectural modifications. Please backup your database and files before upgrading.

Fresh Installation (Recommended)

  1. Download the latest Appointly v1.3.0 package from CodeCanyon
  2. Extract the appointly.zip file from the download
  3. Navigate to Setup → Modules in your Perfex CRM admin panel
  4. Upload the appointly.zip file and click Install
  5. Click Activate to enable the module
  6. If prompted, click Upgrade Database to apply schema changes
  7. Clear your browser cache (Ctrl+F5 on Windows, Cmd+R on Mac)

Upgrading from Previous Versions

  1. Backup Everything - Create full database and file backups
  2. Deactivate the current Appointly module
  3. Replace the module files with the new v1.3.0 files
  4. Reactivate the module
  5. Run database upgrade when prompted
  6. Review and update your settings in Setup → Settings → Appointly
  7. Test all functionality thoroughly

Manual Installation

  1. Extract appointly.zip to your server's modules/ directory
  2. Ensure the folder structure is modules/appointly/[module files]
  3. Set proper file permissions (755 for directories, 644 for files)
  4. Navigate to your Perfex CRM admin panel
  5. Go to Setup → Modules and activate Appointly
  6. Complete the database upgrade process

Post-Installation Steps

  • Configure your services in Appointly → Services
  • Set up staff working hours in Appointly → Staff Working Hours
  • Configure notification templates in Setup → Email Templates
  • Test the external booking form functionality
  • Set up Google Calendar or Outlook integration if needed

System Requirements

Minimum Requirements

  • Perfex CRM: Version 3.0.0 or higher
  • PHP: Version 7.4 or higher (PHP 8.2 recommended)
  • MySQL: Version 5.7 or higher
  • Web Server: Apache 2.4+ or Nginx 1.18+
  • Memory: 256MB minimum (512MB recommended)

Required PHP Extensions

  • cURL (for API integrations)
  • JSON (for data processing)
  • OpenSSL (for secure connections)
  • PDO MySQL (for database operations)
  • GD or ImageMagick (for image processing)

Optional Requirements

  • Cron Jobs: Required for automated reminders and recurring appointments
  • SMS Gateway: For SMS notifications (Twilio, etc.)
  • Email Server: SMTP configuration for email notifications
  • SSL Certificate: Recommended for external booking forms

Important Notes

  • Cron Job Setup: Essential for reminder notifications. Setup Guide
  • SMS Configuration: Required for SMS notifications. SMS Setup Guide
  • Browser Cache: Always clear browser cache after installation or updates

Google Calendar Integration

Seamless two-way synchronization with Google Calendar for real-time availability management.

Step-by-Step Google Calendar Setup

Step 1: Create Google Cloud Project
  1. Go to Google Cloud Console
  2. Click "Select a project" dropdown at the top
  3. Click "New Project"
  4. Enter project name (e.g., "Appointly Calendar Integration")
  5. Click "Create"
  6. Wait for project creation and select your new project
Step 2: Enable Google Calendar API
  1. In the Google Cloud Console, go to APIs & Services → Library
  2. Search for "Google Calendar API"
  3. Click on "Google Calendar API"
  4. Click "Enable"
  5. Wait for the API to be enabled
Step 3: Configure OAuth Consent Screen
  1. Go to APIs & Services → OAuth consent screen
  2. Select "External" user type (unless you have Google Workspace)
  3. Click "Create"
  4. Fill in required fields:
    • App name: Your business name (e.g., "Appointly Calendar")
    • User support email: Your support email
    • Developer contact information: Your email
  5. Click "Save and Continue"
Step 4: Add Required Scopes
  1. On Scopes page, click "Add or Remove Scopes"
  2. Add these scopes:
    • https://www.googleapis.com/auth/calendar
    • https://www.googleapis.com/auth/calendar.events
  3. Click "Update" then "Save and Continue"
Step 5: Add Test Users (Optional)
  1. Add test users if needed for development
  2. Click "Save and Continue"
Step 6: Create OAuth 2.0 Credentials
  1. Go to APIs & Services → Credentials
  2. Click "+ Create Credentials" → "OAuth client ID"
  3. Select "Web application"
  4. Enter name: "Appointly Web Client"
Step 7: Configure Authorized URIs
  1. Add Authorized JavaScript origins:
    • https://your-actual-domain.com (replace with your actual domain)
  2. Add Authorized redirect URIs:
    • https://your-actual-domain.com/appointly/google/auth/oauth
  3. Click "Create"
Step 8: Copy Credentials
  1. Copy the Client ID and Client Secret
  2. Keep these credentials secure - you'll need them for Appointly configuration
Step 9: Publish Your App (For Production)
  1. Go back to OAuth consent screen
  2. Click "Publish App" when ready for production
  3. For testing, you can keep it in testing mode
Step 10: Configure Appointly Settings
  1. In Perfex CRM, go to Setup → Settings → Appointly
  2. Navigate to "Google Calendar Integration" tab
  3. Enter your Google Client ID
  4. Enter your Google Client Secret
  5. Set Redirect URI to your actual domain: https://your-actual-domain.com/appointly/google/auth/oauth
  6. Enable "Google Calendar Sync"
  7. Click "Save Settings"
Step 11: Connect Staff Calendars
  1. Go to Appointly → Staff Working Hours
  2. For each staff member, click "Connect Google Calendar"
  3. Staff will be redirected to Google for authorization
  4. After authorization, calendar sync will be active
  5. Test by creating an appointment and checking Google Calendar

Important Notes

  • Replace placeholder URLs: Always use your actual domain instead of "your-actual-domain.com"
  • HTTPS Required: Google requires HTTPS for production OAuth callbacks
  • Correct Callback URL: Must be exactly https://yourdomain.com/appointly/google/auth/oauth
  • Testing Mode: Apps in testing mode work with up to 100 test users
  • Verification: Production apps may require Google verification for sensitive scopes

Google Calendar Tips

  • Testing: Use a test Google account first
  • Multiple Calendars: Staff can choose which calendar to sync
  • Busy Time: Existing Google events will block appointment slots
  • Meet Links: Enable "Auto-create Google Meet" in settings

Integration Features

  • Two-Way Sync - Appointments sync both directions

  • Busy Time Detection - Automatic conflict prevention
  • Multiple Calendars - Support for multiple Google calendars

Outlook Calendar Integration

Professional integration with Microsoft Outlook and Office 365 calendars.

Step-by-Step Outlook Calendar Setup

Step 1: Access Azure Portal
  1. Go to Azure Portal
  2. Sign in with your Microsoft account (Office 365 admin account preferred)
  3. Navigate to Azure Active Directory
Step 2: Register New Application
  1. Click App registrations in the left menu
  2. Click "+ New registration"
Step 3: Configure Application Details
  1. Fill in application details:
    • Name: "Appointly Calendar Integration"
    • Supported account types: "Accounts in any organizational directory and personal Microsoft accounts"
    • Redirect URI: Web - https://your-actual-domain.com/admin/appointly/appointments
  2. Click "Register"
Step 4: Copy Application ID
  1. Copy the Application (client) ID from the Overview page
  2. Save this ID - you'll need it for Appointly configuration
Step 5: Create Client Secret
  1. In your app registration, go to Certificates & secrets
  2. Click "+ New client secret"
  3. Enter description: "Appointly Client Secret"
  4. Set expiration: "24 months" (recommended)
  5. Click "Add"
  6. Copy the Value (client secret) immediately - it won't be shown again
Step 6: Configure API Permissions
  1. Go to API permissions
  2. Click "+ Add a permission"
  3. Select "Microsoft Graph"
  4. Choose "Delegated permissions"
Step 7: Add Required Permissions
  1. Add these permissions:
    • Calendars.ReadWrite - Read and write user calendars
    • Calendars.ReadWrite.Shared - Read and write shared calendars
    • User.Read - Sign in and read user profile
    • offline_access - Maintain access to data
  2. Click "Add permissions"
  3. Click "Grant admin consent" (if you're admin)
Step 8: Configure Authentication Platform
  1. Go to Authentication
  2. Click "Add a platform"
  3. Select "Web"
  4. Add Redirect URI: https://your-actual-domain.com/admin/appointly/appointments
  5. Under Implicit grant and hybrid flows, check:
    • Access tokens
    • ID tokens
  6. Click "Save"
Step 9: Configure Appointly Settings
  1. In Perfex CRM, go to Setup → Settings → Appointly
  2. Navigate to "Outlook Calendar Integration" tab
  3. Enter your Azure Application ID (Client ID)
  4. Note: Outlook integration uses popup authentication, so no client secret is needed in Appointly settings
  5. Click "Save Settings"
Step 10: Connect Staff Calendars
  1. Go to Appointly → Staff Working Hours
  2. For each staff member, click "Connect Outlook Calendar"
  3. A popup will appear for Microsoft authentication
  4. Staff will sign in with their Office 365/Outlook account
  5. After authorization, calendar sync will be active
  6. Test by creating an appointment and checking Outlook Calendar

Outlook Setup Notes

  • Replace placeholder URLs: Always use your actual domain instead of "your-actual-domain.com"
  • Correct Redirect URI: Must be exactly https://yourdomain.com/admin/appointly/appointments
  • Popup Authentication: Outlook uses popup-based authentication, not traditional OAuth callbacks
  • Admin Consent: Some organizations require admin approval for app permissions
  • Tenant Restrictions: Check with IT if calendar sync doesn't work
  • Personal vs Business: Works with both personal Outlook.com and Office 365 accounts
  • Multiple Accounts: Each staff member connects their own calendar

Outlook Features
