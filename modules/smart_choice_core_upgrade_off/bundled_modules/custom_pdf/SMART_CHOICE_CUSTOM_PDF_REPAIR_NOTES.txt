Smart Choice Custom PDF Repair Notes
Version: 1.1.3
Author: Smart Choice Contractors USA / Harold Cabrera

Purpose:
This repaired module keeps the Custom PDF function: add cover pages, headers, footers, closing pages, and item table styling to proposals, estimates, invoices, credit notes, contracts, and payments while integrating with the native Perfex CRM PDF engine and CRM tables.

Repairs included:
1. Removed unsafe remote image loading for TCPDF section images and changed PDF section images to local filesystem paths under uploads/custom_pdf/.
2. Added safe image checks so missing header, footer, cover, or closing images do not crash PDF generation.
3. Added safer merge field parsing to prevent array/object values from breaking PDF output.
4. Added safer settings loading when JSON options are empty, invalid, or missing.
5. Fixed setup menu slug typo from custom_pdf_settinfs to custom_pdf_settings.
6. Added Smart Choice Contractors USA / Harold Cabrera as author in the module header.
7. Updated module version to 1.1.3.
8. Added PHP 8.5 safer handling for undefined arrays and missing uploaded files.
9. Improved settings save logic so text-only PDF section updates are not rejected when no image is uploaded.
10. Added English and Spanish language paths.
11. Passed PHP syntax check across all module PHP files.

Important:
The reported ParseError in application/vendor/tecnickcom/tcpdf/include/tcpdf_static.php is inside the CRM core vendor TCPDF file, not inside this module ZIP. If that error continues after installing this repaired module, restore the original TCPDF vendor folder from a clean Perfex CRM 3.4.1 package or from a known-good backup.

Recommended install:
1. Back up the current modules/custom_pdf folder.
2. Upload this repaired custom_pdf folder to public_html/crm.justsmartchoice/modules/custom_pdf.
3. Clear CRM cache.
4. Visit Setup > Modules and confirm Custom PDF is active.
5. Visit Setup > Custom PDF.
6. Test proposal PDF and estimate PDF generation.
