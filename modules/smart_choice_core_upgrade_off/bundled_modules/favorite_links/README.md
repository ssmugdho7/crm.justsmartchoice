# Favorite Links - Smart Choice Edition

Version: 2.0.2
Author: Smart Choice Contractors USA / Harold Cabrera
Website: https://www.justsmartchoice.com

## Description
Favorite Links keeps daily CRM shortcuts available beside the Perfex search bar. This Smart Choice edition fixes PHP 8.5 compatibility, broken module asset paths, the non-clickable star issue, mobile search alignment, link normalization, and adds a CRM settings section.

## Settings
Go to:
`Setup > Settings > Favorite Links`

Settings added:
- Enable Favorite Links
- Show star beside CRM search bar
- Open links in new tab
- Enable keyboard hotkeys
- Default link target

## Correct link examples
- `admin/modules`
- `admin/invoices`
- `admin/estimates`
- `https://justsmartchoice.com`

The module automatically corrects common mistakes like `adminmodules`, double slashes, and `ttps://`.
