Smart Choice Field Connector v1.1.0
Author: Smart Choice Contractors USA / Harold Cabrera
Website: https://justsmartchoice.com/
Compatibility: Perfex CRM 3.4.1, PHP 8.5

Install:
1. Upload folder smart_choice_field_connector to public_html/crm.justsmartchoice/modules/.
2. Go to Setup > Modules and activate the module.
3. Click Upgrade Database.
4. Open Smart Choice Field Connector from the main menu or Setup > Smart Choice Field Connector.
5. Run Health Check or Repair Database if tables are missing.

New Features:
- Main menu and setup menu registration.
- English and Spanish language files only.
- No visible front-end underscores in labels.
- Visual Merge Builder with click/drag field chips.
- Field Groups for Marketing, Emails, Contracts, Estimates, Invoices and Project Documents.
- Field Combinations with editable templates.
- Test buttons for builder, mappings, tokens and combinations.
- Pop-up preview showing detected tokens, sample output and missing sample values.
- Edit buttons for groups, mappings, tokens and combinations.
- Health Check.
- Repair Database button.
- PHP 8.5 syntax check passed.

Important:
- Existing data is preserved.
- Internal database names use technical slugs; visible CRM labels are human-readable.
