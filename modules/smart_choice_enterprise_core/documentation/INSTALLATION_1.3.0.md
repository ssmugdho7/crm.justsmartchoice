# Smart Choice Enterprise Core 1.3.0

This is a complete portal-installable replacement package for the existing module. It consolidates Phases 3 through 7 and repairs all missing foundation tables through one idempotent schema installer.

Upload the ZIP from Setup > Modules > Install Module. If the portal asks to replace the existing module, approve replacement. Do not uninstall first. Run the database upgrade when prompted.

The package contains one top-level folder named smart_choice_enterprise_core. Existing operational records and extension tables are preserved.
