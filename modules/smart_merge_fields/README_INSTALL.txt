Install from Perfex CRM:
Setup > Modules > Smart Choice Merge Fields Automation > Activate

Main menu:
Merge Fields Automation

Setup menu:
Setup > Merge Fields Settings

Recommended first steps:
1. Activate module.
2. Open Merge Fields Automation.
3. Click Refresh to scan CRM database fields.
4. Create mappings from source fields to target fields.
5. Set relation fields before running synchronization.
6. Run Health Check after setup.

Safety note:
Synchronization only runs when relation fields are defined. The module blocks obvious password, token, hash, and secret fields from merge field discovery.
