# Smart Module Manager

Author: Smart Choice Contractors USA / Harold Cabrera  
Website: https://justsmartchoice.com

Install folder:
`public_html/crm.justsmartchoice/modules/smart_module_manager/`

This module downloads installed Perfex CRM modules as ZIP packages and can safely unload module folders after creating a backup.

Do not upload core CRM repair ZIP files through the module installer. Only module folders belong in the module installer.
