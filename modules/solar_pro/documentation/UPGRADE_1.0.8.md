# Solar Pro 1.0.8 Upgrade

1. Back up the database, `modules/solar_pro/`, and `uploads/solar_pro/`.
2. Replace the complete module folder.
3. Run the Solar Pro module upgrade from Setup > Modules.
4. Verify proposal templates, PDF export, contract inclusion prompt, email compose, equipment import, and data-sheet uploads.
5. Roll back by restoring the module folder and database backup if required.
