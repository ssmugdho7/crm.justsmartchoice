# Solar Pro 1.1.1 Upgrade

1. Back up the database, modules/solar_pro, and uploads/solar_pro.
2. Replace the complete modules/solar_pro directory.
3. In Setup > Modules, run the Solar Pro upgrade to migration 111.
4. Open Settings > General > Solar Pro and verify every settings section.
5. Verify Solar Pro module pages load without any automatic migration checks.

Rollback: restore the database backup and the previous modules/solar_pro directory.
