Smart Choice Landing Pages v1.1.0

Goal
This package upgrades Zillapage into a Smart Choice branded landing page and lead funnel builder.

What was added
- 50 Smart Choice construction landing page templates
- Facebook and Nextdoor lead funnel templates
- Estimate and proposal delivery templates
- Inspection report style template
- Plumbing, electrical, painting, drywall, flooring, bathroom, kitchen, deck, fence, stucco, roofing, permit, engineering, recruiting, and commercial service templates
- Smart Choice website colors and layout
- Header and footer library references
- AI chatbot library reference
- English and Spanish language files
- Settings page for company data, logo, phone, email, website, CRM portal, appointment link, and tracking IDs
- Google Analytics setting
- Google Tag Manager setting
- Bing tracking setting
- Ahrefs analytics key setting
- Migration 107

Install
1. Replace modules/zillapage with this folder.
2. Go to Setup > Modules.
3. Click Upgrade Database for Smart Choice Landing Pages.
4. Clear application/cache except index.html.
5. Press Ctrl + F5.
6. Open Landing Pages > Templates.

Important
The module keeps the original builder system. The new templates are inserted by migration 107 and do not delete your existing templates or landing pages.

Safety
No landing page data is deleted. Existing templates are preserved. If a Smart Choice template with the same name already exists, the migration updates that template.
